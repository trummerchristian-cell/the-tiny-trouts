THE TINY TROUTS – Website-Entwurf

So verwendest du den Entwurf:
1. ZIP entpacken.
2. Den Ordner the-tiny-trouts-website öffnen.
3. index.html doppelklicken – die Website läuft lokal im Browser.

Wichtig:
- Alle verwendeten Fotos, Videos und das Logo stammen aus euren Uploads.
- Das Logo wurde als Originaldatei eingebunden und nicht neu gezeichnet.
- Die Website ist ein erster, lokal lauffähiger Entwurf. Für eine Veröffentlichung braucht ihr einen kostenlosen Hosting-Anbieter und müsst Die Booking-Adresse tinytrouts07@gmail.com ist bereits eingetragen; Instagram- und Facebook-Links können ergänzt werden, sobald sie vorliegen.
- Die vier Videodateien sind lokal eingebunden. Für kostenloses Hosting kann es sinnvoll sein, Videos später auf einer Videoplattform einzubetten, damit die Website nicht zu gross wird.
